# Customer Behaviour End-to-End Data Analysis
- Project Overview

This project focuses on analyzing customer behaviour using an end-to-end data analytics workflow.
The objective is to understand customer purchasing patterns, trends, and key business insights by using multiple tools across the data analytics pipeline.

- Tools & Technologies Used

Python – Data cleaning, transformation, and analysis

SQL – Data extraction, joins, and analytical queries

Excel – Initial exploration, validation, and quick analysis

Power BI – Interactive dashboards and data visualization

- Dataset Description

The dataset contains customer-level transactional data including:

Customer ID

Order ID

Order Date

Product Category

Purchase Amount

Gender & Age Group

Order Status

Sales Channel

- End-to-End Workflow
1️⃣ Data Collection

Raw data collected in CSV format

Stored and queried using SQL

2️⃣ Data Cleaning & Preparation (Python)

Handled missing values

Removed duplicates

Standardized column names and data types

Created new calculated fields for analysis

Libraries used:

Pandas

NumPy

3️⃣ Data Analysis (SQL & Python)

Customer segmentation by age, gender, and category

Analysis of purchase frequency and sales contribution

Identification of high-value customers

Trend analysis across time periods

4️⃣ Excel Analysis

Quick validation of data

Pivot tables for summary analysis

Cross-checking totals and KPIs

5️⃣ Data Visualization (Power BI)

Created an interactive dashboard to showcase:

Sales & Orders trend over time

Customer distribution by gender and age group

Category-wise and channel-wise performance

Key KPIs for business decision-making

- Key Insights

Certain customer segments contribute a higher share of revenue

Repeat customers show consistent purchasing behaviour

Specific product categories perform better across defined age groups

Clear seasonal trends observed in customer purchases

- Business Impact

Helps businesses understand who their customers are

Supports targeted marketing and personalization

Enables data-driven decisions for sales and inventory planning

- Conclusion

This project demonstrates a complete data analyst workflow, covering:

Data extraction

Data cleaning

Analysis

Visualization

Business insight generation

It reflects real-world data analyst responsibilities using industry-standard tools.
